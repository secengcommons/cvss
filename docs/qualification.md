Qualification is version-specific.

Version | Evidence
--- | ---
2.0 | FIRST guide examples, all 729 Base combinations and every optional metric value
3.0 | FIRST complete examples, all 2,592 Base combinations, rounding boundaries and a version-specific Environmental vector
3.1 | FIRST Base and complete examples, all 2,592 Base combinations, rounding boundaries and a version-specific Environmental vector
4.0 | FIRST's 66,298-record complete reference set, all 270 macrovectors and retained current-rounding corrections

The verification self-test requires targeted qualification tests to kill eight copied-source mutations covering weights, version-specific impact formulae, rounding and the CVSS 4.0 macro score table. Production source is never modified by the mutation run.

The retained corpora prove the covered specification calculations and parser outcomes. They do not certify downstream metric selection or the truth of a vulnerability assessment.

CVSS 1.0 is unsupported because its historical material does not provide a sufficiently deterministic interoperable vector contract.
